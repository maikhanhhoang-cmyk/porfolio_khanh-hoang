# Khánh Hoàng — Portfolio

Repository: `maikhanhhoang-cmyk/porfolio_khanh-hoang`

A responsive Vietnamese-language portfolio built with Next.js App Router, React, and TypeScript. The portfolio includes selected concept case studies, profile, services, and a contact link.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository at [vercel.com/new](https://vercel.com/new). Vercel detects Next.js automatically; the default build command and output settings are ready to use. Alternatively, install the Vercel CLI and run `vercel` from the project directory.

## Personalize before publishing

The project entries are concept case studies, not client endorsements. Replace their names, descriptions, image URLs, and years in `app/page.tsx` with Khánh's real work. Update the contact email and social profile URLs there as well. Project photography is loaded from Unsplash; replace it with approved portfolio images when available.
